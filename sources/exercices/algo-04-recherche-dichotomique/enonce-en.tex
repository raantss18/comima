% English translation (COMIMa) of the original (French) statement.
Write a function \texttt{est\_present(nombres, cible)} that takes a list of integers \texttt{nombres} sorted in increasing order and a value \texttt{cible}, and returns \texttt{True} if \texttt{cible} is a value of \texttt{nombres}, \texttt{False} otherwise.

The binary search algorithm is compulsory: you must not read more than half of the values of \texttt{nombres}, nor use the test \texttt{cible in nombres}.

Examples: \texttt{est\_present([1, 2, 3, 4], 2)}, \texttt{est\_present([1, 2, 3, 4], 1)}, \texttt{est\_present([1, 2, 3, 4], 4)} and \texttt{est\_present([1], 1)} are \texttt{True}; \texttt{est\_present([1, 2, 3, 4], 5)}, \texttt{est\_present([1, 2, 3, 4], 0)}, \texttt{est\_present([1], 0)} and \texttt{est\_present([], 1)} are \texttt{False}.
