Montrer que, pour $x, y, z > 0$,
\[ \text{(a)}\ \frac{x^2}{y^2} + \frac{y^2}{z^2} + \frac{z^2}{x^2} \geq \frac{y}{x} + \frac{z}{y} + \frac{x}{z},\qquad \text{(b)}\ \frac{x^2}{y^2} + \frac{y^2}{z^2} + \frac{z^2}{x^2} \geq \frac{x}{y} + \frac{y}{z} + \frac{z}{x}. \]
