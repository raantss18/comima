Pour quelles valeurs de l'entier naturel non nul $n$ a-t-on :
\begin{enumerate}
  \item $\dfrac{1}{n} \leqslant 0{,}01$ ;
  \item $0{,}49 \leqslant \dfrac{n+13}{2n+25} \leqslant 0{,}51$ ;
  \item $2{,}5 \leqslant \dfrac{1}{0!} + \dfrac{1}{1!} + \dfrac{1}{2!} + \cdots + \dfrac{1}{n!} \leqslant 4$ ?
\end{enumerate}
\emph{Indication pour 2 : écrire $\dfrac{n+13}{2n+25}$ sous la forme
$\dfrac12 + \dfrac{\alpha}{2n+25}$. Pour 3 : comparer $k!$ et $2^{k-1}$.}
