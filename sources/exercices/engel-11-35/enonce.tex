Une fonction $f$ est définie sur l'ensemble des rationnels par
\[ f(0) = 0,\quad f(1) = 1,\quad f(x) = \begin{cases} f(2x)/4 & \text{pour } 0 < x < \frac{1}{2},\\ \frac{3}{4} + f(2x - 1)/4 & \text{pour } \frac{1}{2} \leq x < 1. \end{cases} \]
Soit $a = 0{,}b_1b_2b_3\cdots$ l'écriture de $a$ en base deux. Trouver $f(a)$.
