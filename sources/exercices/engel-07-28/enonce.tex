% Traduction française COMIMa de l'énoncé original (anglais).
On choisit un point sur chaque côté d'un carré de côté $1$. Les quatre points sont les sommets d'un quadrilatère de côtés $a, b, c, d$. Montrer que
\[ 2 \leq a^2 + b^2 + c^2 + d^2 \leq 4 \quad\text{et}\quad 2\sqrt{2} \leq a + b + c + d \leq 4. \]
