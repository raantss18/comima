Soient $m \geq n$, $B_m = \{1, \ldots, m\}$, $B_n = \{1, \ldots, n\}$. Les applications de $B_m$ sur $B_n$ (c'est-à-dire surjectives) s'appellent des \emph{surjections}. Trouver le nombre $s(m, n)$ de surjections de $B_m$ sur $B_n$. Utiliser le principe d'inclusion-exclusion.
