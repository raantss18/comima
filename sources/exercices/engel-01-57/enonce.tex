Partant d'un point $S(a, b)$ du plan avec $0 < a < b$, on construit une suite de points $(x_n, y_n)$ selon la règle
\[ x_0 = a,\quad y_0 = b,\quad x_{n+1} = \sqrt{x_ny_{n+1}},\quad y_{n+1} = \sqrt{x_ny_n}. \]
Montrer qu'il existe un point limite avec $x = y$. Trouver cette limite.
