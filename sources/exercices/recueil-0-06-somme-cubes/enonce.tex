On étudie la formule
\[
1^3 + 2^3 + 3^3 + \cdots + n^3 \ \stackrel{?}{=}\ \left( \frac{n(n+1)}{2} \right)^{2}.
\]
\begin{enumerate}
  \item Calculer la somme pour $n = 1, 2, 3, 4, 5, 6$ et la comparer avec
  $\left( \dfrac{n(n+1)}{2} \right)^{2}$.
  \item Ces quelques vérifications constituent-elles une démonstration ?
  \item Proposer, si possible, un \textbf{raisonnement} général pour prouver
  (ou infirmer) la formule.
\end{enumerate}
\emph{Indication pour 3 : on pose $T_k = \dfrac{k(k+1)}{2}$ ; calculer
$T_k^2 - T_{k-1}^2$.}
