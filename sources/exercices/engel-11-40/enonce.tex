% Traduction française COMIMa de l'énoncé original (anglais).
Trouver toutes les fonctions $f : \mathbb{N}_0 \mapsto \mathbb{N}_0$ (où $\mathbb{N}_0$ est l'ensemble des entiers naturels, $0$ compris) telles que
\[ f[m + f(n)] = f[f(m)] + f(n) \quad\text{pour tous } m, n \in \mathbb{N}_0 \qquad \text{(IMO 1996).} \]
