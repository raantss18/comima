On considère le polynôme $P(n) = n^2 - n + 5$, pour $n$ entier naturel.
\begin{enumerate}
  \item Vérifier que $P(n)$ est premier pour les premières valeurs de $n$.
  \item \textbf{Discussion :} un \emph{grand} nombre d'exemples favorables
  suffirait-il à prouver que $P(n)$ est toujours premier ?
  \item Chercher un entier $n$ pour lequel $P(n)$ est composé.
  \item Reprendre ces questions avec $P(n) = n^2 - n + 11$. Comparer la
  valeur de $n$ trouvée avec celle de la question 3 : que remarque-t-on ?
  \item Reprendre ces questions avec $P(n) = n^2 + n + 41$ (polynôme d'Euler,
  voir aussi la simulation de la page Cours).
  \item Reprendre ces questions avec $F_n = 2^{2^n} + 1$ (nombres de Fermat).
  On pourra calculer à la calculatrice $641 \times 6\,700\,417$ et le
  comparer à $F_5$.
  \item Est-il vrai que, si $p$ est un nombre premier, alors $2^p - 1$ est
  premier ?
\end{enumerate}
