La fonction $f$ est définie sur l'ensemble des entiers strictement positifs par
\[ f(1) = 1,\quad f(3) = 3,\quad f(2n) = f(n),\quad f(4n + 1) = 2f(2n + 1) - f(n),\quad f(4n + 3) = 3f(2n + 1) - 2f(n). \]
Trouver toutes les valeurs de $n$ telles que $f(n) = n$ et $1 \leq n \leq 1988$ (IMO 1988).
