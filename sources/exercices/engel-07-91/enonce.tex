Montrer que, pour des réels $x_1 \geq x_2 \geq \cdots \geq x_n > 0$,
\[ \frac{x_1}{x_2} + \frac{x_2}{x_3} + \cdots + \frac{x_{n-1}}{x_n} + \frac{x_n}{x_1} \leq \frac{x_2}{x_1} + \frac{x_3}{x_2} + \cdots + \frac{x_n}{x_{n-1}} + \frac{x_1}{x_n}. \]
