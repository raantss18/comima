% Traduction française COMIMa de l'énoncé original (anglais).
Trouver toutes les fonctions continues $f : \mathbb{R} \mapsto \mathbb{R}_+$ qui transforment trois termes $x, x + y, x + 2y$ d'une progression arithmétique en trois termes $f(x), f(x + y), f(x + 2y)$ d'une progression géométrique, c'est-à-dire
\[ [f(x + y)]^2 = f(x) \cdot f(x + 2y). \]
