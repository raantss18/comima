Trois suites $(x_n), (y_n), (z_n)$, $n = 1, 2, \ldots$, sont définies par
\[ x_1 = 2,\ y_1 = 4,\ z_1 = \frac{6}{7},\qquad x_{n+1} = \frac{2x_n}{x_n^2 - 1},\quad y_{n+1} = \frac{2y_n}{y_n^2 - 1},\quad z_{n+1} = \frac{2z_n}{z_n^2 - 1}. \]
(a) Montrer que cette construction peut se poursuivre indéfiniment.

(b) Peut-on avoir, à une certaine étape, $x_n + y_n + z_n = 0$ (ARO 1990) ?
