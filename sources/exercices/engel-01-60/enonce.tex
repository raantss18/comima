Partant d'un point $S(a, b)$ du plan avec $0 < b < a$, on construit une suite de points $S_n(x_n, y_n)$ selon la règle
\[ x_0 = a,\quad y_0 = b,\quad x_{n+1} = \frac{2x_ny_n}{x_n + y_n},\quad y_{n+1} = \frac{2x_{n+1}y_n}{x_{n+1} + y_n}. \]
Montrer qu'il existe un point limite avec $x = y$. Trouver cette limite.
