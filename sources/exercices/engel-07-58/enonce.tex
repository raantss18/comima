Soient $x, y, z$ les longueurs des côtés d'un triangle, et soit
\[ f(x, y, z) = \left|\frac{x - y}{x + y} + \frac{y - z}{y + z} + \frac{z - x}{z + x}\right|. \]
Montrer que (a) $f(x, y, z) < 1$ ; (b) $f(x, y, z) < 1/8$ ; (c) trouver la borne supérieure de $f(x, y, z)$.
