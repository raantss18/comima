Soient $x, y, z$ des réels strictement positifs tels que $xy + yz + zx = 1$. Démontrer l'inégalité
\[ \frac{2x(1 - x^2)}{(1 + x^2)^2} + \frac{2y(1 - y^2)}{(1 + y^2)^2} + \frac{2z(1 - z^2)}{(1 + z^2)^2} \leq \frac{x}{1 + x^2} + \frac{y}{1 + y^2} + \frac{z}{1 + z^2}. \]
