A function $d(x, y)$ of two points is a \emph{distance} if $d(x, y) = d(y, x)$, $d(x, z) \leq d(x, y) + d(y, z)$ for all $x, y, z$, and $d(x, x) = 0$. The second property is called \emph{triangle inequality}. Prove that the following function is a distance:
\[ d(x, y) = \frac{|x - y|}{\sqrt{1 + x^2}\sqrt{1 + y^2}}. \]
