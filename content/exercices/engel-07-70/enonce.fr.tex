Une fonction $d(x, y)$ de deux points est une \emph{distance} si $d(x, y) = d(y, x)$, si $d(x, z) \leq d(x, y) + d(y, z)$ pour tous $x, y, z$, et si $d(x, x) = 0$. La deuxième propriété s'appelle l'\emph{inégalité triangulaire}. Montrer que la fonction suivante, définie pour $x, y$ réels, est une distance :
\[ d(x, y) = \frac{|x - y|}{\sqrt{1 + x^2}\sqrt{1 + y^2}}. \]
