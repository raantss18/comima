Montrer que, pour $a, b, c > 0$,
\[ \text{(a)}\ \frac{a^2 + b^2}{a + b} \geq \frac{a + b}{2},\qquad \text{(b)}\ \frac{a^3 + b^3 + c^3}{a^2 + b^2 + c^2} \geq \frac{a + b + c}{3},\qquad \text{(c)}\ \frac{a + b + c}{3} \geq \sqrt{\frac{ab + bc + ca}{3}} \geq \sqrt[3]{abc}. \]
