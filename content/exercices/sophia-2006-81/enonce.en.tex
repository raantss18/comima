% English translation (COMIMa) of the original (French) statement.
Let $A = \{1, 2, 3, 4, 5\}$. Count the functions $f : \mathfrak{P}(A) \to A$ such that:
\begin{itemize}
\item $\forall B \subseteq A$, $f(B) \in B$
\item $\forall B, C \subseteq A$, $f(B \cup C) = f(B)$ or $f(C)$
\end{itemize}
Here $\mathfrak{P}(A)$ denotes the set of subsets of $A$.
