On considère un quadrilatère de côtés consécutifs $a, b, c, d$, d'angles consécutifs $\alpha, \beta, \gamma, \delta$ et d'aire $A$, et les trois énoncés suivants :

$(U)$ : \emph{le quadrilatère est inscriptible dans un cercle} $\iff \alpha + \gamma = \beta + \delta = 180^\circ$ ;

$(I)$ : \emph{le quadrilatère admet un cercle inscrit} $\iff a + c = b + d$ ;

$(A)$ : \emph{l'aire du quadrilatère vaut} $A = \sqrt{abcd}$.

\emph{Montrer que} $(U), (I) \Rightarrow (A)$, $\quad (U), (A) \Rightarrow (I)$, $\quad (I), (A) \Rightarrow (U)$.
