% English translation (COMIMa) of the original (French) statement.
Write a function \texttt{tri\_selection(tableau)} that sorts a list of integers \texttt{tableau} \emph{in place} (the list is modified), in increasing order.

Use the following algorithm: go through the list from left to right; at each position, find the minimum of the list between this position and the end, then swap these two values.

Examples: after \texttt{tri\_selection(tab)} with \texttt{tab = [1, 52, 6, -9, 12]}, \texttt{tab} is \texttt{[-9, 1, 6, 12, 52]}; an empty list stays empty; \texttt{[9]} stays \texttt{[9]}.
