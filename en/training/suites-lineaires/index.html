Linear recurrence sequences

A sequence defined by $a_{n+2} = p\,a_{n+1} + q\,a_n$ (with $a_0, a_1$ given) is a linear recurrence of order 2.

  • A geometric sequence $r^n$ is a solution if and only if $r$ is a root of the characteristic equation $r^2 = p\,r + q$.
  • If this equation has two distinct roots $r_1, r_2$, every solution is $a_n = A\,r_1^n + B\,r_2^n$; find $A, B$ from $a_0$ and $a_1$.
  • Key example: Fibonacci, $r^2 = r + 1$, roots $\frac{1 \pm \sqrt5}{2}$.

Other tools: compute the first terms, look for a conserved quantity (invariant), count tilings with a recurrence.
