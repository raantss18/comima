Iteration, injectivity and recursion

Respect the domain: an identity on positive integers does not allow substituting $0$. A function is injective if $f(u)=f(v)$ implies $u=v$. If an equation expresses $y$ using $f(y)$, compare two arguments with the same image.

Equations involving $f(f(x))$ call for successive substitutions. Verifying a candidate does not prove uniqueness.

In binary recursions, $f(2n)=f(n)$ deletes a final zero. Rules for $4n+1$ and $4n+3$ concern the last two bits. For dyadic fractions, $2x$ and $2x-1$ remove the leading binary bit. These recursions can be evaluated exactly.
