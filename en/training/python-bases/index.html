Python basics

A Python program is a sequence of instructions run from top to bottom. A variable is a name attached to a value: x = 7 stores $7$ in x; x = x + 1 first computes x + 1, then stores the result in x.

Common types: integers (7), floats (3.5), booleans (True, False), strings ("hello"), lists ([4, 1, 7]).

Division: 7 / 2 is 3.5 (a float); 7 // 2 is 3 (integer quotient) and 7 % 2 is 1 (remainder). So n % 2 == 0 tests whether $n$ is even.

Conditions: if …:, elif …:, else:. The block that depends on a line ending with : is indented by 4 spaces: indentation is what delimits blocks.

Loops: for i in range(n): repeats the block for $i = 0, 1, \dots, n-1$ ($n$ rounds); while condition: repeats as long as the condition is true (make sure it changes, otherwise the loop never stops).

Lists and strings: l[0] is the first element, l[-1] the last, len(l) the length; l.append(x) adds x at the end. A string is traversed like a list: for c in "abc":.

Functions: def f(n): defines a function; return gives back the result and stops the function. Key example, the digit sum:

def somme_chiffres(n):
    s = 0
    while n > 0:
        s = s + n % 10   # last digit
        n = n // 10      # remove it
    return s

For $n = 2026$: $s$ takes the values $6, 8, 8, 10$ and the function returns $10$. To understand a program, trace it by hand: write down the value of each variable after each line.
