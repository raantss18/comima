The extremal principle

Every non-empty set of natural numbers has a least element, and every finite non-empty set of reals has a least and a greatest element. This is no longer guaranteed for an infinite set of reals: $(0, 1]$ has no least element.

Method: consider the extremal object (smallest, largest, longest…), after checking that it exists, then use this choice; often, one shows that an even more extremal object would exist: contradiction.

Variant: infinite descent (a strictly decreasing sequence of natural numbers is finite).
