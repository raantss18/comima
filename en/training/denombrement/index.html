Counting

  • Product rule: if we make a choice among $p$ possibilities, then a choice among $q$ possibilities (whatever the first choice), there are $pq$ possibilities in total.
  • $n! = n(n-1)\cdots 2\cdot 1$ (with $0! = 1$) is the number of ways to arrange $n$ distinct objects in a row.
  • For $0 \le k \le n$, the number of ways to choose $k$ objects among $n$ ignoring the order is $\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}$ (also written $C(n,k)$); with order: $\dfrac{n!}{(n-k)!}$.
  • Anagrams: $n$ objects split into kinds of $n_1, n_2, \dots, n_r$ identical objects can be arranged in $\dfrac{n!}{n_1!\,n_2!\cdots n_r!}$ ways.
  • A set with $n$ elements has $2^n$ subsets (the empty set and the whole set included).
