Basic algorithms in Python

An algorithm is a method that solves a problem in finitely many steps. A few classics to know how to write and trace:

  • Traversal: read a list element by element while updating a variable (sum, counter, largest seen so far).
  • Euclid: $\operatorname{gcd}(a, b) = \operatorname{gcd}(b, a \bmod b)$, and $\operatorname{gcd}(a, 0) = a$. The remainder decreases at every round, so the loop stops.
  • Sieve of Eratosthenes: write $2, 3, \dots, n$; keep the smallest number not crossed out (it is prime) and cross out its multiples; one can stop as soon as $p \times p > n$.
  • Sorting: bubble sort swaps two badly ordered neighbours; after each pass, the largest remaining element is in place.
  • Binary search: in a sorted list, compare with the middle and keep the useful half. For $1000$ elements, about ten comparisons are enough ($2^{10} = 1024$) instead of $1000$.

Key example, Euclid:

def pgcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

For pgcd(48, 18): $(48, 18) \to (18, 12) \to (12, 6) \to (6, 0)$, result $6$. The assignment a, b = b, a % b computes both new values before storing them.

To check an algorithm: trace it by hand on a small example, then test the edge cases (empty list, a single element, equal values, $0$ and $1$).
