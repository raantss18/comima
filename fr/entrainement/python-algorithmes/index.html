Algorithmes de base en Python

Un algorithme est une méthode qui résout un problème en un nombre fini d'étapes. Quelques classiques, à savoir écrire et dérouler :

  • Parcours : on lit une liste élément par élément en tenant à jour une variable (somme, compteur, plus grand vu jusqu'ici).
  • Euclide : $\operatorname{pgcd}(a, b) = \operatorname{pgcd}(b, a \bmod b)$, et $\operatorname{pgcd}(a, 0) = a$. Le reste diminue à chaque tour, donc la boucle s'arrête.
  • Crible d'Ératosthène : on écrit $2, 3, \dots, n$ ; on garde le plus petit nombre non barré (il est premier) et on barre ses multiples ; on peut s'arrêter dès que $p \times p > n$.
  • Tri : le tri à bulles échange deux voisins mal rangés ; après chaque passage, le plus grand élément restant est à sa place.
  • Recherche dichotomique : dans une liste triée, on compare au milieu et on garde la moitié utile. Pour $1000$ éléments, une dizaine de comparaisons suffisent ($2^{10} = 1024$), au lieu de $1000$.

Exemple clé, Euclide :

def pgcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

Pour pgcd(48, 18) : $(48, 18) \to (18, 12) \to (12, 6) \to (6, 0)$, résultat $6$. L'affectation a, b = b, a % b calcule les deux nouvelles valeurs avant de les ranger.

Pour vérifier un algorithme : le dérouler à la main sur un petit exemple, puis tester les cas limites (liste vide, un seul élément, valeurs égales, $0$ et $1$).
