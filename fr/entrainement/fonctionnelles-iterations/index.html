Itérations, injectivité et récursions

Respecte le domaine : une identité sur les entiers positifs ne permet pas la substitution $0$. Une fonction $f$ est injective si $f(u)=f(v)$ implique $u=v$. Si une équation exprime $y$ à partir de $f(y)$, compare deux arguments ayant la même image.

Une équation avec $f(f(x))$ se traite par substitutions successives. Vérifier une candidate ne prouve pas son unicité.

Dans les récursions binaires, $f(2n)=f(n)$ supprime un zéro final. Les règles pour $4n+1$ et $4n+3$ concernent les deux derniers chiffres. Pour les fractions dyadiques, les transformations $2x$ et $2x-1$ retirent le premier chiffre binaire. Ces récursions se calculent exactement sans décimales approchées.
