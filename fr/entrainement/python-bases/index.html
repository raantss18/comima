Les bases de Python

Un programme Python est une suite d'instructions exécutées de haut en bas. Une variable est un nom posé sur une valeur : x = 7 range $7$ dans x ; x = x + 1 calcule d'abord x + 1, puis range le résultat dans x.

Types courants : entiers (7), flottants (3.5), booléens (True, False), chaînes ("bonjour"), listes ([4, 1, 7]).

Division : 7 / 2 vaut 3.5 (un flottant) ; 7 // 2 vaut 3 (quotient entier) et 7 % 2 vaut 1 (reste). Ainsi n % 2 == 0 teste si $n$ est pair.

Conditions : if … :, elif … :, else:. Le bloc qui dépend d'une ligne terminée par : est décalé de 4 espaces : c'est l'indentation qui délimite les blocs.

Boucles : for i in range(n): répète le bloc pour $i = 0, 1, \dots, n-1$ ($n$ tours) ; while condition: répète tant que la condition est vraie (penser à la faire changer, sinon la boucle ne s'arrête pas).

Listes et chaînes : l[0] est le premier élément, l[-1] le dernier, len(l) la longueur ; l.append(x) ajoute x à la fin. Une chaîne se parcourt comme une liste : for c in "abc":.

Fonctions : def f(n): définit une fonction ; return renvoie le résultat et arrête la fonction. Exemple clé, la somme des chiffres :

def somme_chiffres(n):
    s = 0
    while n > 0:
        s = s + n % 10   # dernier chiffre
        n = n // 10      # on l'enlève
    return s

Pour $n = 2026$ : $s$ prend les valeurs $6, 8, 8, 10$ et la fonction renvoie $10$. Pour comprendre un programme, déroule-le à la main : note la valeur de chaque variable après chaque ligne.
